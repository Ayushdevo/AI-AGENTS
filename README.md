# AI Agent Builder

A React application for building and chatting with custom AI agents using Anthropic's Claude API.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file in the root directory and add your Anthropic API key:
```
VITE_ANTHROPIC_API_KEY=your_api_key_here
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Features

- Create custom AI agents with:
  - Name and role
  - Personality traits
  - Expertise areas
  - Special instructions
- Chat with your created agents
- Manage multiple agents

## Note

You'll need an Anthropic API key to use the chat functionality. Get one from [Anthropic's website](https://www.anthropic.com/).
